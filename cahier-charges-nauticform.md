## 2. STYLE & DESIGN FRONT-END

### 2.1 Philosophie de Design

**Principes directeurs** :
- ✨ **Moderne et épuré** : Éviter la surcharge visuelle, faveur au blanc et à l'espace blanc
- 🎯 **Efficacité visuelle** : Information pertinente au premier coup d'œil, sans texte superflu
- 🧭 **Navigation intuitive** : Chaque section accessible en moins de 3 clics
- 📱 **Responsive** : Expérience optimale desktop, tablette, mobile
- ⚓ **Connexion maritime** : Touches nautiques subtiles, pas kitsch
- ✅ **Accessibilité** : Contraste suffisant, lisibilité maximale

---

### 2.2 Palette Couleurs

**Couleurs principales** :
- **Bleu océan** : #0D6E9E (couleur primaire, CTA, accents)
  - Nuances : #0A5280 (hover), #084063 (active)
- **Blanc/Beige** : #FAFAF8 ou #F5F3F0 (fond pages)
- **Gris charbon** : #2C2C2C (texte principal, contraste élevé)
- **Accent teal/turquoise** : #1ABDB5 (pour éléments secondaires, éléments nautiques)

**Palette étendue** :
- Gris clair : #E8E8E8 (bordures, séparations)
- Vert marin (pour validations) : #2E8B7D
- Orange maritime (pour appels à action secondaires) : #E8885E
- Transparences : max 85% pour maintenir la clarté

---

### 2.3 Typographie

**Polices de caractères** :
- **Titres & Headers** (h1-h6) : 'Inter', 'Helvetica Neue', sans-serif
  - Poids : Semibold (600) ou Bold (700)
  - Spacing : Lettrage augmenté légèrement pour impact

- **Corps de texte** (paragraphes, listes) : 'Inter' ou 'Open Sans'
  - Poids : Regular (400)
  - Taille : 16px base, 14px sur mobile
  - Line-height : 1.6 minimum

- **Éléments UI** (boutons, labels) : 'Inter'
  - Poids : Medium (500)
  - Casse : Sentence case (non tout en majuscules)

**Hiérarchie typographique** :
```
h1 : 42px (mobile: 32px)
h2 : 32px (mobile: 24px)
h3 : 24px (mobile: 20px)
h4 : 20px
p  : 16px
small : 14px
```

---

### 2.4 Composants & Éléments UI

#### Boutons

**Styles principaux** :

1. **Primary (CTA majeurs)**
   - Couleur : Bleu océan (#0D6E9E)
   - Texte : Blanc
   - Hover : Bleu foncé (#0A5280)
   - Padding : 12px 32px
   - Border-radius : 6px
   - Icône optionnelle (flèche droite)

2. **Secondary (Actions secondaires)**
   - Couleur : Bordure gris clair, texte gris foncé
   - Hover : Fond gris très léger
   - Padding : 12px 32px
   - Même border-radius

3. **Outline (Moins d'importance)**
   - Couleur : Bordure fine gris moyen, texte foncé
   - Hover : Fond transparent légèrement grisé
   - État actif : Bordure bleu océan

#### Cartes (Cards)

- Fond : Blanc ou beige très léger
- Bordure : 1px gris très léger ou ombre très subtile
- Padding : 24px
- Hover : Ombre légère, élévation visuelle légère
- Image optionnelle en haut (si pertinent)
- Icône petit format 48x48px (couleur bleu ou teal)

#### Formulaires

- Labels au-dessus des champs
- Champs : bordure gris léger, focus bleu océan
- Placeholder : texte gris moyen (non trop foncé)
- Validation : vert marin pour succès, rouge doux pour erreurs
- Spacing entre éléments : 16px minimum

#### Sections

- **Alternance fond** : Blanc puis beige très clair, pour créer rythme
- **Padding** : 60px horizontalement, 80px verticalement (desktop)
- **Max-width container** : 1200px centré
- **Largeur colonne** : optimisée pour lecture (70 caractères environ)

---

### 2.5 Mise en Page & Espacement

**Grille de base** : Système d'espacement de 4px ou 8px

```
Margins/Paddings standards :
8px, 16px, 24px, 32px, 48px, 64px
```

**Sections principales** :

1. **Navigation** (Header)
   - Hauteur : 64px
   - Position : Sticky en scroll
   - Fond : Blanc avec bordure inférieure fine
   - Logo + Menu horizontal + Bouton CTA principal

2. **Héro Section**
   - Hauteur : 500px-600px (ajustable)
   - Image fond ou gradient nautique subtle
   - Texte centré ou légèrement décalé (left/center)
   - Overlay : 30% noir transparent pour lisibilité texte blanc

3. **Contenu standard**
   - 2-3 colonnes max sur desktop
   - 1 colonne sur mobile (naturellement)
   - Espacement entre colonnes : 32px

4. **Footer**
   - Fond : Gris charbon (#2C2C2C) ou bleu océan foncé
   - Texte : Blanc
   - 3-4 colonnes de liens + newsletter optionnel
   - Hauteur : 300px+

---

### 2.6 Imagerie & Iconographie

**Imagerie** :
- Photographies haute qualité de bateaux, formations, moniteurs
- Images lifestyle (personnes heureuses, nature, eau)
- Format : JPG optimisé, lazy loading
- Pas d'images trop kitsch ou excessives

**Iconographie** :
- Style : Outline ou solid, cohérent
- Couleur : Bleu océan ou teal selon contexte
- Taille : 24px-48px selon usage
- Sources : FontAwesome, Feather Icons, ou iconographie personnalisée nautique
- Exemples :
  - ⚓ (ancre) = sécurité/stabilité
  - 🛥️ (bateau) = formations
  - 🎓 (graduation) = certification
  - 📍 (localisation) = adresse/sites

---

### 2.7 Animations & Micro-interactions

**Principes** :
- Subtilité : animations <300ms
- Feedback utilisateur : interaction = réaction visuelle
- Pas de flash ou clignotement

**Exemples** :
- Hover boutons : changement couleur (150ms) + légère élévation ombre
- Survol cartes : légère translation vers le haut (100ms)
- Hover liens : underline animé en reveal de bas en haut
- Scroll : sections qui fade-in progressivement (parallax discret possible)
- Loading : spinner simple bleu océan (SVG préféré)

---

### 2.8 Responsive & Mobile First

**Breakpoints** :
```
Mobile    : < 640px
Tablet    : 640px - 1024px
Desktop   : > 1024px
```

**Adaptation mobile** :
- Menu hamburger à partir de 768px
- Stacking des colonnes
- Typographie réduite (voir section typographie)
- Boutons : taille minimale 44x44px pour touch
- Espacement : réduit mais fonctionnel

---
